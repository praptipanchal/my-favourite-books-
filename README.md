📚# my-favourite-books_# 

A simple and beginner-friendly **Favourite Books Website** created using **HTML and CSS**.
The website displays a collection of my favourite books and provides separate pages to explore individual books.
## Live Demo
https://praptipanchal.github.io/my-favourite-books-/

## 🌟 Features

* 📖 Displays a list of favourite books
* 🔗 Each book can be opened on a separate page
* 🖼️ Book cover images
* 🎨 Simple and clean design
* 📱 Beginner-friendly web project
* 📚 Includes books such as:

  * Atomic Habits
  * The Psychology of Money
  * Deep Work
  * Think and Grow Rich
  * Rich Dad Poor Dad
  * The Almanack of Naval Ravikant
  * The 7 Habits of Highly Effective People
  * Thank you for Leaving
  * I don't Love you anymore
  * I Cannot say GoodBye to you

## 🛠️ Technologies Used

* HTML5
* CSS3
